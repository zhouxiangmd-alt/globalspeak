# GlobalSpeak · 医生国际交流与学术场景口语教练 (V1 PWA)

面向参加国际学术会议、海外手术交流及跨国同行破冰的医生打造的 **Mobile-First PWA Web 应用**。

## 核心功能 (V1)

1. **专属场景选择卡 (Scenario Hub)**：内置 4 大高频实战场景（美食与咖啡、国际会议社交、海外手术与学术交流、出行与突发应急），深度贴合赴欧洲/土耳其参会语境。
2. **实战语音沙盒 (Roleplay Sandbox)**：
   - **盲听优先**：AI 默认播放英文语音并折叠文字，支持单句/全局切换原文与 `0.8x` 慢速重播。
   - **救生圈 (Hint)**：卡壳时一键查看 2 条中文思路与地道英文短语，支持试听发音或填入输入框。
   - **三模输入兜底**：原生语音（适配 iPhone Safari 按住/轻点双兼容手势）+ 无麦克风模拟语音 + 文字输入。
3. **“去僵硬”社交体检卡 (Social Nuance Feedback)**：3～5 轮速练后生成「原文 vs. 地道平替」词级对比、文化潜台词点拨，支持一键存入金句本。
4. **私人金句本 (Pocket Phrasebook)**：支持复盘一键收录、手动自建金句、场景标签筛选、置顶星标，以及 **美音 (US) / 英音 (UK)** 与 **1.0x / 0.8x 慢速跟读**。
5. **双模 AI 与真人神经网络语音引擎**：默认内置高拟真离线沙盒免 Key 开箱体验；在「偏好设置」填入 **Gemini API Key** 或 **OpenAI 兼容接口** 后，同一份 Key 同时驱动真实大模型对话、结构化体检与真人级神经网络语音（OpenAI `/v1/audio/speech` + `gpt-4o-mini-tts` 场景语气 `instructions` / Gemini 原生语音 PCM→WAV 前端播放），支持音频缓存防重复扣费、语速精细调节与异常平滑回退浏览器离线朗读。

## 本地运行

```bash
pnpm install
pnpm dev
```

生产构建与本地预览：

```bash
pnpm build
pnpm preview
```

## iPhone Safari 实机使用与添加到主屏幕建议

- **添加到主屏幕 (PWA)**：在 iPhone Safari 打开部署后的 HTTPS 地址 → 点击底部「分享」→「添加到主屏幕」，即可以无地址栏全屏 App 形态运行并离线访问金句本。
- **麦克风与语音识别**：iPhone Safari 仅在 **HTTPS** 地址下开放麦克风权限；若提示语音识别不可用，请检查 `设置 → Safari 浏览器 → 麦克风` 与 `设置 → 通用 → 键盘 → 启用听写`（同时确认机身左侧静音拨片未开启静音）。在医院值班室或非 HTTPS 局域网预览时，可直接切换内置的「模拟语音」或「文字输入」无缝演练。
